# 2026-10-13

## Methodology run on the `AI-random-bs-go` offshoot (solo experiment)

Ran the `coding_assistant` (planning_graph) methodology on RentMate as a **solo
experiment** — the point was to see how the IP → CP → PG → gate pipeline behaves on
a real, messy repo, not to contribute to the team's docs.

### What was found

The repo carried **three incompatible statements of the product**: the team-agreed
interim report, the unratified `docs/site-spec-suite/` draft, and
`HK_Rental_Platform_Master_Cursor_Spec.md` (a landlord/tenant marketplace — what
`backend/supabase/` was actually built against). Nothing said which one wins, so
the build had drifted.

### Owner decisions encoded (these overruled the docs)

- **Gender is a HARD filter** — it gates candidates before scoring and never enters
  the score. Overrides IP v1's blanket "gender cannot influence the score" (which
  conflated "cannot exclude" with "cannot score").
- **MBTI is a SOFT scoring preference** — one scored factor
  (`1 - differing_axes/4`), best elicited through lifestyle questions, not a bare
  4-letter code.
- **12 questions** is the demo boundary (report spec was 22; earlier demo had 7).
- **Do not build on Figma** (owner's call).
- **U6 left open**: Figma vs the root Vite app, and the hosting consequence (root
  app presented on-screen means localhost `npm run dev` or Vercel hosting).

### What was built / changed (commit `2d94b0b`)

- `vault/ips/IP.rentmate.v2.md` — intent tree from the owner's stated intent (supersedes v1).
- `vault/cps/CP.calculate_match.v2.md` — MBTI added as a seventh equal-weight factor;
  gender stays excluded. Oracle grown to 8 cases.
- `vault/PG.rentmate.v2.json` — rebuilt from the v2 corpus.
- `vault/NOTES.md` — the agent's informal views (drift, overrules, what the
  methodology is worth, what was deleted).
- `vault/checks/rentmate_reference_impls.py` — MBTI-aware formulations.
- **Deleted** the contradictory/unratified prose (PRD.md, TEAM-BRIEF.md,
  site-spec-suite, HK_Rental spec, build-plans, open-decisions, pitch-and-data-pack,
  interim-report-reconciliation, v0-mvp-prompt) + superseded v1 artifacts.
  **`main` still holds every removed file** — restore with `git checkout main -- <path>`.
- Updated `README.md` and the `rentmate-conventions` skill with branch banners.

### Checks (all green)

`ip_tool`/`cp_tool validate` 0 hard · `ip_tool link` clean (3 orphans reported) ·
`g1_harness` 8/8 on both formulations, no disagreement · PG 0 hard/0 soft, coverage
ok, staleness ok. **G-8 human boundary NOT exercised** (owner waived it) — declared
in `vault/README.md`, not faked. No S-9 independence record (one author, two

### Methodology verdict

Worth keeping: the IP as single stated intent; CPs for the deterministic functions;
the oracle + two-implementation check. Mostly ceremony at this scale: the PG
coverage/staleness numbers, and full doc-reconciliation discipline.
