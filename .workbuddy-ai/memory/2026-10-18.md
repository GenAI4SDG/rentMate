# 2026-10-18 — Merge dedup & build repair

Context: teammate merged `AI-random-bs-go` (offshoot) into `main` with a "keep all
changes" resolution, which produced a broken `Figma/src/App.tsx` (two `export default
function App()` + a concatenated `Workspace`) and a concatenated `Figma/src/lib/supabase.ts`
with a duplicated `isSupabaseConfigured` export. Both `npm run build` blockers.

What I did:
- Collapsed the duplicated `App.tsx` into a single clean shell. The landlord and
  roommate flows already coexisted in ONE `App.tsx` (views: `landlord-entry`,
  `landlord-dashboard`; Workspace tabs: matches/messages/flats/plan). The previously
  extracted `LandlordApp.tsx`/`RoommateApp.tsx` were byte-identical, so the split was
  redundant and removed.
- Unified `lib/supabase.ts` into one module: eager `supabase` client, `backendMode`,
  function-form `isSupabaseConfigured()` (call sites use it as a function), `getSupabase()`,
  and `AmenityRow` type. All call sites in `BackendHealthCheck`, `LandlordEntry`,
  `LandlordDashboard`, `api.ts`, `landlordApi.ts`, `personalStore.ts` preserved.
- `npm run build` now passes (118 modules, no errors; only a >500kB chunk warning).

Git: committed on `AI-random-bs-go` as `830d7e9`, then **fast-forwarded `main` to it**.
`main` was strictly behind (it only had `19dbf61`); the FF pulled in 80 files of the
merged history, so `main` now contains BOTH branches. Pushed both → Render auto-deploys `main`.

Notes for the team:
- Chat "messages don't send" was a SYMPTOM of the broken build (app couldn't render),
  not a logic bug. `sendMessage` in `App.tsx` is correct (preventDefault + append + clear).
- Map "could not load listings" is a DEPLOY-CONFIG issue, not code: on the static web
  service `VITE_MAP_API_URL` must be set to the `rentmate-map-api` service URL, otherwise
  the frontend calls same-origin `/api/*` and 404s. Set it in the Render web service env.
- Optional: a `tsc --noEmit` pass would surface any latent type errors from the messy
  merge; the vite build (esbuild) does not type-check, so it won't catch them.
